What's a fingerprint?

A SHA-256 fingerprint is a 64-character code made from a piece of text. The same text always gives the same code. Change a single letter and the code changes completely.

my.commbank.com.au/…
SHA-256
d3da20…f7786b ✓
my.cornmbank.com.au/…
SHA-256
1c0ec5…7c379d ✗
One tiny change ("rn" instead of "m") gives a totally different fingerprint.
A match meansthe address is exactly the one we published, not a look-alike.
A match doesn't meanthis page is genuine or your device is safe. Someone who copied this page could change both. Compare against a printout or a friend's copy too.
